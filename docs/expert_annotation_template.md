# 手势词典 Agent 专家标注模板

本文档用于组织专家标注两类内容：

- `术语类型`：哪些词可以作为手势词典 Agent 的规范术语，以及它属于哪一类术语。
- `Intent 输出框架`：不同 intent 应该按什么结构回答；这里的“输出框架”就是最终回答中的栏目顺序，不再另设“输出栏目”概念。

## 0. 当前口径

### 0.1 术语层级和术语类型的关系

当前标注不再区分“术语层级”和“术语类型”。

历史代码中的 `layer` 更像检索和文档切块用的内部分类，例如 `interaction_mechanism`、`control_form`、`basic_property`。专家标注时不需要维护这套 layer。专家只判断一个词是否应进入术语库，以及它的 `术语类型`。

标注口径：

- `术语类型` 是专家标注的唯一术语分类字段。
- 一个术语只能优先归入一个主类型；如果确实跨类型，在“关联术语 / 专家备注”中说明。
- `layer` 不出现在标注表中，后续可由系统根据 `术语类型` 自动映射。
- 输出框架中的栏目名称不作为术语收录，除非它本身也是词典概念，例如“微变”“响应逻辑”。

### 0.2 Intent 输出框架和输出栏目的关系

当前标注不再区分“Intent 输出框架”和“输出栏目”。

`Intent 输出框架` 就是一组有顺序的回答栏目。比如 `design_evaluation` 的输出框架是：

```text
方案复述 -> 结构拆解 -> 问题诊断 -> 修改建议 -> 规范术语版本 -> 需要补充的信息
```

标注口径：

- 不再单独维护“输出栏目字段表”。
- 每个 intent 只标注一个 `Intent 输出框架`。
- 如果需要解释某个框架项应该写什么，直接在同一行的“框架项说明”中说明。
- 框架项名称应稳定，避免同一含义出现多个叫法。

## 2. 术语类型标注

### 2.1 标注目标

判断候选词是否应该进入 `term_inventory`，并确定：

- 规范术语是什么。
- 术语类型是什么。
- 哪些说法可以映射到它。
- 哪些说法应该避免或纠正。
- 它适用和不适用的边界是什么。

### 2.2 术语类型可选值

| 术语类型 | 说明 | 示例 |
| --- | --- | --- |
| 基础属性 | 描述输入、控件或被控对象的基础属性 | 二元属性、位置属性、时间属性、角度属性 |
| 控件形态 | 承载交互的控件、身体部位或输入形态 | 按钮、旋钮、触控面、手势 |
| 基础交互机制 | 独立、基础、可直接识别的交互机制 | 单击、按下、长按、拖拽、滑动 |
| 高级交互机制 | 组合、调和、冲突解决或扩展类机制 | 快击、点击缓冲、长按拖拽、点拖互斥 |
| 响应类型 | 描述系统状态变化或响应方式 | 赋值、微变、跳转、确认反馈 |
| 交互特性 | 描述交互机制的体验属性或评价维度 | 响应速度、容错性、确认感、误触风险 |
| 多模态交互 | 与视觉、语音、触觉等模态组合相关的术语 | 模态分工、歧义校准、跨模态反馈 |
| 语音交互 | 语音输入、声学属性、口令和反馈相关术语 | 唤醒词、声控、语音反馈 |
| 背景概念 | 理论背景、设计原则或方法论概念 | 操控力、虚拟操控力、声明式交互 |
| 待定 | 专家暂时无法判断，需要二次讨论 |  |

### 3.3 标注结果导入项目

标注完成后，不直接让程序读取本 Markdown 表格；需要把审核通过的内容整理为两个 JSON 配置文件。

术语类型导入到 `data/term_inventory.json`：

```json
{
  "mode": "merge",
  "by_type": {
    "基础交互机制": ["单击", "双击", "长按", "拖拽"],
    "高级交互机制": ["快击", "点击缓冲", "长按拖拽", "点拖互斥"],
    "控件形态": ["按钮", "旋钮", "触控面"],
    "基础属性": ["二元属性", "位置属性", "时间属性"],
    "响应类型": ["微变", "确认反馈"]
  }
}
```

Intent 输出框架导入到 `data/output_frames.json`：

```json
{
  "mode": "merge",
  "frames": {
    "design_evaluation": ["方案复述", "结构拆解", "问题诊断", "修改建议", "规范术语版本", "需要补充的信息"],
    "interaction_compare": ["对比对象", "共同基础", "核心差异", "适用边界", "选择建议"]
  }
}
```

导入后可以用以下命令检查当前生效配置：

```bash
uv run python -m gesture_agent.cli --show-term-inventory
uv run python -m gesture_agent.cli --show-output-frames
```
